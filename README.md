# The Navratri Hot Seat

A full-screen office game-show quiz built for Navratri and GitHub Pages.

## Included

- 15-question score ladder up to 1,000,000 points
- Four lifelines: 50:50, Ask the Office, Ask a Colleague, Switch Question
- 45-second question timer
- Random question selection across Navratri, India, culture, sport, science, food, film and world trivia
- Local ambient and champion MP4 animations
- Original browser-generated sound cues
- Fullscreen projector mode and responsive mobile layout
- Local browser leaderboard
- Host keyboard controls

## Host keys

- 1–4: choose A–D
- Enter: lock answer
- Space: next question after a correct answer
- H: open host console
- P: pause/resume the timer
- R: reveal the correct answer
- M: mute/unmute

## Publish

In GitHub: Settings → Pages → Deploy from a branch → main / root.
